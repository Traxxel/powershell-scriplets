# PowerShell Scriptlets

A collection of PowerShell scripts for Microsoft 365 administration.

## Available Scripts

### Teams Channel Owner Analysis
`teams-list-channelowners/teams-list-channelowners.ps1`
Lists all Teams channels and their owners, including channel activity status.
[Teams Channel Owner Analysis README](teams-list-channelowners/README.md).

## Requirements

- PowerShell 7 or later
- Appropriate permissions for each script's functionality

## Installation

Each script will automatically install required PowerShell modules if they are not already present on your system.
